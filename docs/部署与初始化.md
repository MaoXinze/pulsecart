# PulseCart 本地部署与初始化

## 前置条件

开发机建议使用 Python 3.12 虚拟环境。当前主机的 Python 3.14 可以运行纯数据与模型单元测试，但未安装 SQLAlchemy，不能据此宣称运营后端已完成真实数据库验证。Docker Desktop、MySQL、Redis 和 Milvus 的本机安装情况需在 Docker CLI 恢复可用后再做 Compose 验收。

不将密码写入 Git。复制 `jeecg-fastapi/.env.example`（若项目已有）为 `.env.local`，至少修改 `DATABASE_URL` 与 `SIGNATURE_SECRET`。NLP 服务的模型和训练任务可通过下面两个环境变量放到 D 盘持久化目录：

```text
PULSECART_MODEL_ROOT=D:\pulsecart-data\models
PULSECART_TRAINING_JOB_ROOT=D:\pulsecart-data\training-jobs
```

## MySQL 初始化顺序

PulseCart 在继承的 JeecgBoot 数据库中新增独立 `pc_` 前缀表，不修改 `sys_*` 系统表。

1. 首次搭建时先执行继承项目的 `jeecg-fastapi/sql/jeecgboot-slim.sql`，创建基础系统表与初始账号。
2. 在目标库 `jeecg-boot` 中执行 `jeecg-fastapi/sql/pulsecart_domain.sql`，创建 `pc_dataset_import`、`pc_review`、`pc_review_task`、`pc_analysis_run` 与 `pc_issue`。
3. 重复执行上述 DDL 是安全的，因为 DDL 使用 `CREATE TABLE IF NOT EXISTS`；它不是模式迁移工具。以后表结构改变时，应新增带版本号的迁移文件，不能静默修改已发布 SQL。

执行示例中的凭据仅是命令位置说明，应替换为本地实际值：

```powershell
mysql -u <user> -p < jeecg-fastapi/sql/jeecgboot-slim.sql
mysql -u <user> -p jeecg-boot < jeecg-fastapi/sql/pulsecart_domain.sql
```

## 开发模式

`dev` 模式中，MySQL、Redis、Milvus、MinIO 由 Compose 运行；运营后端、NLP 服务和前端在本机启动以便断点调试。当前仓库尚未在此主机检测到可用 Docker CLI，因此下列服务组合是设计目标，不标为已验收部署。

```text
Vue 3 工作台 :3100
       |
运营后端 :8006/jeecg-boot  ----> MySQL / Redis / MinIO
       |
NLP 服务 :8100  ----> 本地模型产物与训练任务目录
```

分别进入 `jeecg-fastapi` 和 `sentiment-ai` 后启动两个 Python 服务。NLP 服务可先单独验证：

```powershell
uvicorn app.main:app --host 127.0.0.1 --port 8100
python scripts/run_training_worker.py --limit 1
```

初始没有人工审核训练数据时，`GET /healthz` 返回 `not_ready` 是正确行为。不要为了演示把 `synthetic_reference_labels.jsonl` 送入训练接口，也不要提交生成的模型文件和指标。

## 演示验收顺序

1. 以 `admin / 123456` 登录 Vue 工作台，进入默认的“PulseCart 商品体验 -> 体验问题闭环”，点击“初始化本地演示数据”；也可调用 `POST /jeecg-boot/api/v1/demo/bootstrap`，确认数据集版本 `ds-9b8a078d8df7010a` 和 300 条待审核任务。
2. 以商品运营角色完成足量审核；数据分析师复核 10% 样本并保留分歧。
3. 创建分析运行，Worker 将完成的审核记录提交到 NLP 训练任务；任务成功后核对模型版本、数据指纹、混淆矩阵与 SHA-256。
4. 使用显式 `model_version` 批量推理，人工确认候选并创建问题卡。
5. 按状态机处理问题并填写关闭验证说明。演示页面、接口和数据库记录应能回查同一数据集、模型版本与评论证据。

完整接口字段见 [PulseCart 接口契约](api/PulseCart接口契约.md)。
